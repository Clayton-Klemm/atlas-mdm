# Security reporting

This repository is a local demonstration, not a hosted enterprise service. Only the current main branch is maintained; there is no formal support SLA.

If GitHub's private vulnerability reporting is enabled, use the repository's **Security → Report a vulnerability** action. Otherwise use a private contact method explicitly published by [the maintainer](https://github.com/Clayton-Klemm). Do not post working credentials, session cookies, tokens, backups or sensitive records in public issues.

Include the affected commit, environment, reproduction steps, expected/actual behavior and impact using fictional data. A public issue is appropriate for a non-sensitive hardening suggestion. See [security scope and limitations](docs/security.md) before deploying this demo beyond localhost.
